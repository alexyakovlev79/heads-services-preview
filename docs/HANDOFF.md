# Heads /services/ — актуальная передача состояния

Дата фиксации: **12 ноября 2026 года**. Рабочий репозиторий: https://github.com/alexyakovlev79/heads-services-preview (приватный), ветка `main`. Источник: https://wellhead.ru/services/.

## Итог: готовая к согласованию GEO/AEO-версия

1. Сохранена исходная HTML-копия WordPress-страницы и 223 ресурса в `assets/`; глобальное меню, подвал, анимации, четыре исходные категории услуг и форма не удалены.
2. В `index.html` добавлены полностью видимые в исходном HTML блоки:
   - вводный коммерческий ответ об услугах полного цикла Heads / ранее Wellhead;
   - 5 этапов: аналитика → стратегия и позиционирование → нейминг и креатив → айдентика и упаковка → коммуникации и запуск;
   - 3 сценария: новый бренд, ребрендинг, портфель СТМ;
   - 4 кратких доказательных карточки с прямыми ссылками на официальные кейсы;
   - обоснование индивидуальной сметы со ссылкой на прайс;
   - 7 раскрывающихся FAQ и CTA к исходной форме «Обсудить проект».
3. Обновлены H1, Title, Description, OG и **существующий** Yoast JSON-LD: один Organization, WebPage и OfferCatalog (4 категории); добавлены Service и FAQPage, факты FAQ соответствуют видимому тексту. Канонический URL остался https://wellhead.ru/services/.
4. Новая верстка оформлена в `geo-enhancements.css`, строго ограничена CSS-классом `.heads-geo`. Исходную верстку WordPress не переписывали.

## Решения пользователя от 12.11

- Переносить или исправлять PDF презентации **не нужно**: оставляем существующую ссылку, даже если она битая.
- Закрытый URL предпросмотра **не требуется**. Никаких дополнительных настроек Pages ради этого не делать.
- **Менять основной wellhead.ru пока не поручено**; работаем с копией и после согласования переносим на существующий URL. Обе формы копии демонстрационные, без отправки данных.

## Следующий шаг при новом поручении

Если пользователь просит еще правки, работать с `main`, менять только нужные фрагменты, фиксировать коммит и проверять GitHub Actions. Если просит перенос на рабочий сайт, использовать канонические компоненты и WordPress/Yoast на действующем `/services/`, не загружать локальный `index.html` вместо всего сайта, не создавать дублей Schema.org и обязательно проверить публичную страницу на десктопе/мобиле.

### Как открыть локально

```sh
python3 -m http.server 8000 --bind 127.0.0.1
node scripts/check-preview.mjs
node scripts/check-geo.mjs
```

Адрес локального просмотра: http://127.0.0.1:8000/. Для `check-browser.mjs` нужны Chrome и `playwright-core`; GitHub Actions устанавливает драйвер автоматически.
