# HEADS services preview — передача состояния (12 ноября 2026)

## Канон

- Рабочая ветка: `main`.
- Источник: https://wellhead.ru/services/
- Репозиторий: https://github.com/alexyakovlev79/heads-services-preview (приватный).
- Цель: сохранить точную рабочую копию исходной страницы, согласовать GEO/AEO-доработки в отдельном предпросмотре и только после разрешения переносить на wellhead.ru.
- **Рабочий сайт изменять нельзя без отдельного поручения.** Не публиковать предпросмотр публично без решения о защите доступа.

## Подтвержденный результат

- Полная статическая копия исходной HTML-страницы и 223 локальных ресурса: CSS, шрифты, изображения, анимации, JS и бриф DOCX.
- В `index.html` сохранены 4 исходные категории, исходные ссылки на узкие услуги, навигация и подвал.
- Две формы демонстрационные: обработка локальная, без передачи пользовательских данных; `form-action 'none'`, CSP, `noindex`.
- Окно «Скачать презентацию» открывается и закрывается с десктопа и доступно из мобильного Sidr-меню. Презентация пока открывается **по внешнему URL** на wellhead.ru, сам PDF в репозитории отсутствует.
- Маска телефона, проверка формата, согласие, размер вложения 10 МБ, работа при отсутствии части библиотек и управление переключателями услуг с клавиатуры.
- `scripts/check-preview.mjs` — проверка наличия ресурсов, безопасности демоформ и синтаксиса JS (Node без зависимостей).
- `scripts/check-browser.mjs` — настоящие тесты Playwright/Chrome: 4 категории, переключение, попап, обе формы, маска телефона, ограничение вложения, отсутствие POST, ширина 390 px, открытие мобильного меню и наличие ссылки на презентацию.
- `.github/workflows/preview-qa.yml` — проверки при каждом `push` в main, Chrome-скриншоты десктопа и мобильной версии, публикуются в артефактах GitHub Actions.

## Нерешенное, не выдавать за выполненное

1. **Оригинальный 12-страничный PDF Heads**: точный файл в репозиторий пока не перенесен. Ссылка в `preview.js`: `https://wellhead.ru/wp-content/themes/total-child-theme/presentation/about_HEADS_2026.pdf`. Попытка внешней проверки из текущей среды не подтвердила доступность PDF.
2. **Защищенный URL показа клиенту**: приватный GitHub-репозиторий сам по себе не делает опубликованный GitHub Pages приватным. Настройки Pages/доступа и отдельный пароль не подтверждены; живую публичную ссылку не объявлять.
3. **GEO/AEO-верстка второго этапа**: новая последовательность «исследование → стратегия → позиционирование → нейминг/дизайн → коммуникации», 3 сценария (новый бренд, ребрендинг, СТМ/портфель), CTA и согласованные кейсы пока не добавлены: сперва закончили исходную копию.
4. **Права на кейсы**: перед расширением страницы обязательно сверить переписку с Аллой, Ольгой и действующие ограничения на публикации. Не использовать автоматически все кейсы старого плана, включая ранее исключенные.

## Локальное тестирование

```sh
python3 -m http.server 8000 --bind 127.0.0.1
node scripts/check-preview.mjs
npm install --no-save --no-package-lock --ignore-scripts playwright-core
node scripts/check-browser.mjs  # требуется запущенный localhost:8000 и Chrome
```

Все действия этого цикла проводились через GitHub connector и GitHub Actions, без Work-режима и без изменения wellhead.ru.
