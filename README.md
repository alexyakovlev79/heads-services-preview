# Страница услуг Heads — предпросмотр

Копия действующей страницы [wellhead.ru/services/](https://wellhead.ru/services/), сохраненная 11 ноября 2026 года для обсуждения и дальнейших GEO/AEO-доработок. **Основной сайт этим репозиторием не изменяется.** Работа ведется в ветке `main`.

## Что уже перенесено

- `index.html` — исходная структура страницы, шапка, 4 категории услуг, подвал и форма.
- `assets/` — локальные стили, шрифты, изображения, анимации, сценарии и бриф DOCX.
- `preview.js`, `preview.css` — только адаптация поведения для автономного предпросмотра, без изменения исходной структуры услуг.
- Кнопка «Скачать презентацию» открывает форму, включая доступ через мобильное меню; после заполнения демоформы предлагается **внешняя** ссылка на PDF с wellhead.ru. PDF пока не включен в репозиторий.
- Обе формы демонстрационные: **данные и прикрепленные файлы никуда не отправляются**. Аналитика отключена. Превью закрыто от индексации метатегом `noindex`.

## Как посмотреть локально

Скачайте репозиторий с GitHub («Code» → «Download ZIP»), распакуйте его и в полученной папке выполните:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8000/`. Открывать `index.html` через `file://` нежелательно: часть локальных ресурсов может работать иначе.

## Автоматическая проверка файлов

```sh
node scripts/check-preview.mjs
```

Проверяются локальные ссылки и ресурсы HTML/CSS, наличие 4 категорий, двух демоформ, мобильного меню, окна презентации, ограничения сетевых отправок, `noindex`, а также синтаксис `preview.js`. Требуется Node.js 18+; сторонние пакеты не нужны. **Визуальное тестирование и загрузку внешнего PDF эта проверка не заменяет.**

## Проверка перед согласованием с Heads

1. На десктопе: логотип, меню, 4 категории услуг, анимации, ссылки на узкие услуги, форма «Обсудить проект».
2. На мобильных ширинах 390 и 320 px: раскрытие меню, отсутствие горизонтальной прокрутки, переключение категорий, модальное окно презентации, закрытие окна.
3. В форме заявки: обязательные поля, маска телефона, согласие, файл до 10 МБ и сообщение об отсутствии реальной отправки.
4. В окне презентации: проверка email, согласие, закрытие крестиком и Escape, ссылка на полный PDF.
5. Если утверждается новая GEO-версия: проверка 3 сценариев обращения, состава этапов и разрешенных кейсов. Проект «Фрутанго» без нового согласования в перечень примеров не добавлять.

## Доступность предпросмотра

Репозиторий **приватный**. GitHub Pages из приватного репозитория может создавать **публично доступный сайт** (уровень доступа зависит от плана GitHub и настроек Pages). `noindex` скрывает страницу от роботов, но не защищает URL паролем. Настройка Pages должна быть проверена в **Settings → Pages**; пока точный рабочий адрес Pages и приватность показа не подтверждены. Не следует сообщать клиенту, что ссылка «закрытая», без отдельной проверки прав доступа.

Внешние ссылки (разделы сайта, кейсы, презентация и виджет отзывов) могут вести на действующий wellhead.ru / сторонние ресурсы. Для полной автономности потребуется отдельно перенести оригинальный PDF и проверить сторонние виджеты.
