# Страница услуг Heads

Исходная версия [wellhead.ru/services/](https://wellhead.ru/services/) для правок и согласования. Зафиксирована 11 ноября 2026 года.

Для локального просмотра запусти команду в корне репозитория и открой [страницу в браузере](http://127.0.0.1:8000/).

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

- В `index.html` находится разметка действующей страницы. В `assets/` сохранены её стили, шрифты, иллюстрации и анимации. Бриф открывается из локальной копии.
- Формы заявки и скачивания презентации имитируют отправку в браузере. После проверки формы презентации появляется ссылка на открытый PDF Heads. Сторонний виджет отзывов в подвале и ссылки на другие страницы открывают исходные адреса.
- Сценарии аналитики отключены. Предпросмотр предназначен для закрытого доступа.
