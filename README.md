# Страница услуг Heads — предпросмотр

Копия действующей страницы [wellhead.ru/services/](https://wellhead.ru/services/), сохраненная 11 ноября 2026 года для обсуждения и дальнейших GEO/AEO-доработок. **Основной сайт этим репозиторием не изменяется.** Работа ведется в ветке `main`.

## Что уже перенесено

- `index.html` — исходная структура страницы, шапка, 4 категории услуг, подвал и форма.
- `assets/` — локальные стили, шрифты, изображения, анимации, сценарии и бриф DOCX.
- `preview.js`, `preview.css` — только адаптация поведения для автономного предпросмотра, без изменения исходной структуры услуг.
- Кнопка «Скачать презентацию» открывает форму, включая доступ через мобильное меню; после заполнения демоформы предлагается **внешняя** ссылка на PDF с wellhead.ru. PDF пока не включен в репозиторий.
- Обе формы демонстрационные: **данные и прикрепленные файлы никуда не отправляются**. Аналитика отключена. Превью закрыто от индексации метатегом `noindex`.

## GEO/AEO-доработки, 12 ноября 2026

Доработки в `main` добавлены к оригинальной копии, без изменения рабочего wellhead.ru.

- Новый H1 и вводный блок, который сразу объясняет услуги полного цикла и аудиторию: FMCG, ритейл, СТМ.
- Пять этапов: аналитика → стратегия и позиционирование → нейминг и креатив → айдентика и упаковка → коммуникации и запуск. Ссылки ведут на существующие услуги.
- Три сценария покупателя: новый бренд, ребрендинг, развитие СТМ и портфеля.
- Четыре публичных доказательных кейса: KIX, Pet Pride, Hartens, «Вернель». В описаниях сохранены реальные границы работ.
- Семь раскрывающихся вопросов о составе, стратегии, отдельных услугах, стоимости, СТМ, сроках и старте.
- Блок индивидуального расчета стоимости со ссылкой на действующий прайс, CTA к исходной форме.
- Отдельные стили `geo-enhancements.css`, обновленные Title/Description/OG и единый JSON-LD: WebPage, Organization, OfferCatalog (4 категории), Service, FAQPage.

**Исключения по кейсам:** не упоминать в новых блоках «Фрутанго», Smart Cooking/«Блиночкин», «Крыницу», Ringle/«Рингл» и неопубликованные работы. Hartens нельзя описывать как новый нейминг, «Вернель» нельзя выдавать за создание новой стратегии. В существующую исходную верстку меню и формы вмешиваться без необходимости нельзя.

**Проверка:** `node scripts/check-geo.mjs` проверяет точность 4 ссылок на кейсы, 7 внутренних ссылок, семантику, FAQ и JSON-LD. `node scripts/check-browser.mjs` проверяет работу интерфейса и ширины 320, 390, 768 и 1440 px, а также создает полноразмерные снимки страницы.

Успешная автоматическая проверка: https://github.com/alexyakovlev79/heads-services-preview/actions/runs/43247457295

**Следующий этап:** согласование изменений, затем перенос в WordPress на тот же URL `/services/`. При переносе использовать штатный шаблон и исходные глобальные компоненты; не заменять всю страницу на файл `index.html`. SEO-теги и JSON-LD обновлять в каноническом источнике WordPress/Yoast, не создавать дубли.

**Отдельные решения пользователя:** исходную ссылку на PDF оставить как есть, даже если она не открывается; защищенный адрес предпросмотра не требуется. Ничего не менять ради этих двух пунктов.

### Редакторские правила для публичной страницы

В обращениях к посетителю используем только **«вы»**, в кейсах говорим **от лица Heads («мы»)**. Внутренние согласования, запреты и редакторские ремарки категорически нельзя помещать в публичный текст. При любой правке проверяем всю страницу и данные FAQ/Schema.org. Подробности: [docs/HANDOFF.md](docs/HANDOFF.md). Автоматическая проверка: `node scripts/check-geo.mjs`.

## Как посмотреть локально

Скачайте репозиторий с GitHub («Code» → «Download ZIP»), распакуйте его и в полученной папке выполните:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8000/`. Открывать `index.html` через `file://` нежелательно: часть локальных ресурсов может работать иначе.

## Автоматическая проверка файлов

```sh
node scripts/check-preview.mjs
```

Проверяются локальные ссылки и ресурсы HTML/CSS, наличие 4 категорий, двух демоформ, мобильного меню, окна презентации, ограничения сетевых отправок, `noindex`, а также синтаксис `preview.js`. Требуется Node.js 18+; сторонние пакеты не нужны. **Визуальное тестирование и загрузку внешнего PDF эта проверка не заменяет.**

## Проверка перед согласованием с Heads

1. На десктопе: логотип, меню, 4 категории услуг, анимации, ссылки на узкие услуги, форма «Обсудить проект».
2. На мобильных ширинах 390 и 320 px: раскрытие меню, отсутствие горизонтальной прокрутки, переключение категорий, модальное окно презентации, закрытие окна.
3. В форме заявки: обязательные поля, маска телефона, согласие, файл до 10 МБ и сообщение об отсутствии реальной отправки.
4. В окне презентации: проверка email, согласие, закрытие и наличие прежней ссылки; доступность внешнего PDF по решению пользователя не проверяем.
5. Если утверждается новая GEO-версия: проверка 3 сценариев обращения, состава этапов и разрешенных кейсов. Проект «Фрутанго» без нового согласования в перечень примеров не добавлять.

## Статус и принятые ограничения

**GEO/AEO-версия полностью подготовлена в публичном репозитории и прошла проверки GitHub Actions.** На самом wellhead.ru изменений пока нет. Новые блоки потребуется перенести в существующий WordPress-шаблон после согласования с Heads.

- Ссылка на PDF презентации оставлена без исправлений по прямому решению пользователя от 12 ноября 2026 года; возможная недоступность файла допустима.
- Отдельный защищенный адрес просмотра создавать не требуется. Для просмотра есть [живая страница GitHub Pages](https://alexyakovlev79.github.io/heads-services-preview/), репозиторий и снимки из GitHub Actions.
- Исходные две формы в предпросмотре намеренно не отправляют данные; на рабочем сайте используются реальные формы и требуют самостоятельной проверки после переноса.
- При дальнейших правках читать `docs/HANDOFF.md` как актуальную передачу состояния, проверять последний успешный запуск Actions и не начинать сборку заново.

Подтвержденный успешный прогон: [GitHub Actions — 43247457295](https://github.com/alexyakovlev79/heads-services-preview/actions/runs/43247457295). В его артефакте есть обычные и полноразмерные снимки для десктопа и мобильного экрана.
